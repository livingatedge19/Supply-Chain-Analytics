# Bitfinex API Setup

## Create your API key

1. Log in to Bitfinex → top-right avatar → **API Keys**
2. Click **Create New Key**
3. Under permissions, enable **Orders: Write** and **Margin Trading: Write** if needed
4. Leave **Withdraw** off
5. Set a label and click **Generate API Key**
6. Complete 2FA and copy your **API Key** and **API Secret**

## Credentials needed

| Variable | Description |
|---|---|
| `BITGET_API_KEY` | Your Bitfinex API key |
| `BITGET_SECRET_KEY` | Your Bitfinex API secret |
| `BITGET_PASSPHRASE` | Leave blank |
