# MEXC API Setup

## Create your API key

1. Log in to MEXC → top-right avatar → **API Management**
2. Click **Create API Key**
3. Set a note/label for the key
4. Enable **Spot Trading** permissions
5. Leave **Withdrawal** off
6. Complete 2FA and copy your **Access Key** and **Secret Key**

## Credentials needed

| Variable | Description |
|---|---|
| `BITGET_API_KEY` | Your MEXC access key |
| `BITGET_SECRET_KEY` | Your MEXC secret key |
| `BITGET_PASSPHRASE` | Leave blank |
