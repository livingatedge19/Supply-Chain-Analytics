# OKX API Setup

## Create your API key

1. Log in to OKX → top-right avatar → **API**
2. Click **Create V5 API Key**
3. Give it a name and set a **Passphrase** (required — write it down)
4. Under permissions, enable **Trade**; leave **Withdraw** off
5. (Optional) Add an IP whitelist
6. Complete 2FA and save your **API Key**, **Secret Key**, and **Passphrase**

## Credentials needed

| Variable | Description |
|---|---|
| `BITGET_API_KEY` | Your OKX API key |
| `BITGET_SECRET_KEY` | Your OKX secret key |
| `BITGET_PASSPHRASE` | The passphrase you set |
