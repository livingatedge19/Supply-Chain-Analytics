# KuCoin API Setup

## Create your API key

1. Log in to KuCoin → top-right avatar → **API Management**
2. Click **Create API**
3. Set a name and a **Passphrase** (required — write it down)
4. Enable **General** + **Spot Trading** permissions
5. Leave **Futures Trading** and **Transfer** off unless needed
6. Complete 2FA and copy your **API Key**, **Secret**, and **Passphrase**

## Credentials needed

| Variable | Description |
|---|---|
| `BITGET_API_KEY` | Your KuCoin API key |
| `BITGET_SECRET_KEY` | Your KuCoin API secret |
| `BITGET_PASSPHRASE` | The passphrase you set |
