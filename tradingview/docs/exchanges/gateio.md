# Gate.io API Setup

## Create your API key

1. Log in to Gate.io → top-right avatar → **API Management**
2. Click **Create API Key**
3. Set a name and enable **Spot Trade** permissions
4. Leave **Withdrawal** off
5. (Optional) Add an IP whitelist
6. Complete 2FA and copy your **API Key** and **Secret Key**

## Credentials needed

| Variable | Description |
|---|---|
| `BITGET_API_KEY` | Your Gate.io API key |
| `BITGET_SECRET_KEY` | Your Gate.io secret key |
| `BITGET_PASSPHRASE` | Leave blank |
